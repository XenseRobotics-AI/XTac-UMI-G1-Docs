# 认识 XTac-UMI G1

XTac-UMI G1 是千觉的多模态 UMI 数采夹爪：操作员手持主夹爪完成人类示范，指尖视触觉、腕部鱼眼与位姿同步录下；从夹爪装在机器人末端，用来执行或回放动作。

![XTac-UMI G1 产品外观](../assets/product/xtac-umi-g1-hero.webp){ width="720" }

## 系统组成

| 部件 | 作用 |
|---|---|
| 主夹爪 ×2（左 / 右） | 手持完成人类示范；每只集成 2 个视触觉传感器、腕部鱼眼相机、开合编码器与 IMU，见[夹爪连接与序列号](../common/gripper.md) |
| Pico4 Ultra 运动追踪器 ×2 | 装在主夹爪顶部，提供夹爪的 6-DoF 位姿 |
| Pico4 Ultra 企业版头显 | 跟踪追踪器、建立世界坐标系，可同时录第一视角双目画面，见 [Pico4 头显与追踪器](../common/pico4.md) |
| 采集单元 | 背包版是[数采背包](backpack.md)，PC 版是您自己的工作站，见[产品线与配置对比](editions.md) |
| 从夹爪（选配） | 装在机器人末端执行或回放动作，见[从夹爪](../follower/index.md) |

规格见[技术参数](specs.md)。

## 数据流 {#dataflow}

## 两种配置的关键差别

| | 背包版 | PC 版 |
|---|---|---|
| 预览 | 浏览器控制台，平板即可 | Rerun 窗口 |
| 录制控制 | 夹爪按键为主，控制台也可操作 | `lerobot-record` 命令行 |
| 落盘 | 每条人类示范一个 MCAP 原始记录 | 直接写 LeRobotDataset v3 |
| 数据出口 | 按任务导出 LeRobot v3 / MCAP，一键发布到 ModelScope | 推送到 Hugging Face Hub |
| 开源 | 否 | 是（Apache-2.0） |

两种配置记录的位姿坐标系一致，见[坐标系](../common/coordinates.md)。完整对比、箱内清单与接线见[产品线与配置对比](editions.md)。

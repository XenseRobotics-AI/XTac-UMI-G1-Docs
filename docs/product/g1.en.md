# XTac-UMI G1

XTac-UMI G1 is Xense's multimodal UMI data-collection gripper: the operator demonstrates with the leader gripper in hand while fingertip visuotactile sensing, the wrist fisheye and pose are recorded in sync; the follower gripper mounts on a robot to execute or replay motions.

![XTac-UMI G1 product photo](../assets/product/xtac-umi-g1-hero.webp){ width="720" }

## System components

| Part | Role |
|---|---|
| Leader grippers ×2 (left / right) | Handheld demonstration; each carries two visuotactile sensors, a wrist fisheye camera, an opening encoder and an IMU, see [Gripper connection and serial numbers](../common/gripper.md) |
| Pico4 Ultra motion trackers ×2 | Mounted on top of the leader grippers, giving their 6-DoF pose |
| Pico4 Ultra Enterprise headset | Tracks the trackers and sets the world frame; can also record a first-person stereo view, see [Pico4 headset and trackers](../common/pico4.md) |
| Collection unit | The [backpack](backpack.md) on the Backpack Kit, your own workstation on the Developer Kit, see [Editions](editions.md) |
| Follower grippers (optional) | Mounted on a robot to execute or replay motions, see [Follower gripper](../follower/index.md) |

Specifications are in [Specifications](specs.md).

## Key differences between the kits

| | Backpack Kit | Developer Kit |
|---|---|---|
| Preview | Browser console, a tablet is enough | Rerun window |
| Recording control | Mainly the gripper buttons; the console works too | `lerobot-record` command line |
| On disk | One MCAP raw recording per take | LeRobotDataset v3 directly |
| Data out | Export per task as LeRobot v3 / MCAP, upload to ModelScope in one click | Push to the Hugging Face Hub |
| Open source | No | Yes (Apache-2.0) |

Both kits record poses in the same coordinate frame, see [Coordinate frames](../common/coordinates.md). The full comparison, box contents and wiring are in [Editions](editions.md).

# 技术参数

本页是 XTac-UMI G1 夹爪与数采背包的规格表,选型、写方案、核对接口时查这里;接线步骤见[夹爪按键、指示灯与序列号](../common/gripper.md#install),背包与 PC 两种配置的取舍见[产品线与配置对比](editions.md)。

## XTac-UMI G1 {#specs}

电气与接口见[供电与连接要求](../common/gripper.md#install)。下表是传感器与整机规格;采集时实际速率可按需配置(如 PC 版触觉以较低帧率录制),不改变传感器规格。

| 参数项 | 规格 |
|---|---|
| 夹爪类型 / 外形 | 二指结构;145 × 186 × 170 mm |
| 重量(主爪)/ 负载 | 约 370 g;最大 2.5 kg |
| 开合行程 / 角度 | 0–150 mm;角度行程每台各异,以标定写入固件的实测值为准(背包版在控制台 系统 → 夹爪配置 页标定,PC 版见[夹爪标定](../pc/calibration.md#41)) |
| 供电 | 主夹爪无内置电池,由 USB Type-C 总线供电(DC 5V/500mA);从夹爪 24V 适配器供电 |
| 多设备时间同步 / 定位 | 5 ms;< 3 mm |
| 视触觉 | 2 × 三色光,量程 0–25 N,120 FPS(640×480 MJPG) |
| IMU | 9 轴,100 Hz |
| 腕部鱼眼相机 | FOV 190°;640×480 @ 30 FPS MJPG |
| 位姿 | Pico4 Ultra 运动追踪器,6-DoF,坐标系定义见[坐标系](../common/coordinates.md) |
| 输出数据 | RGB、多模态触觉、夹爪开口角度、IMU、空间定位轨迹 |

内部通信:对外接口为 USB Type-C;内部 MCU 串口经 CH343(`1a86:55d2`)桥接,枚举为 `/dev/ttyACM*`,USART3 @ 3 Mbps;视触觉与腕相机为 UVC(`/dev/video*`);从爪经 FDCAN1 @ 1 Mbps 透传灵足电机。

## 数采背包

数采背包是背包版的采集单元:夹爪、头显都接到它上面,XTac-UMI Collector 在它上面运行,控制台通过浏览器打开。产品定位与使用方式见[认识数采背包](backpack.md)。

| 参数项 | 规格 |
|---|---|
| 计算节点 | RK3588(Xense-3588Q) |
| 存储 | eMMC 系统盘 + NVMe 数据盘,episode 记录与导出都落在数据盘 |
| 供电输入 | `DC` 口,随货 12V 3A 36W 适配器,或 Type-C 输出 12V3A 的充电宝 |
| 网络 | 有线网口(DHCP,可改静态);WiFi 客户端,只连 5 GHz;自建热点 SoftAP `xense-<序列号后 6 位>`,同样只有 5 GHz,网关固定 `192.168.44.1` |
| 电池 / 续航 | 待补 |
| 整机功耗 | 待补 |
| 防护等级 | 待补 |

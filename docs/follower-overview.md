# 从夹爪概览

从夹爪(Follower)是装在机器人末端、由电机驱动的那一只夹爪。主夹爪是拿在手里**读**的
——编码器、IMU、开合角;从夹爪是**驱动**的——内置电机,由程序控制开合与夹持力。
本章讲怎样用 `xense.taccap` SDK 直接控制从夹爪。

!!! warning "本章按 SDK 0.3.2 独立安装编写"
    本章所有命令、接口与报错原文都按 [TacCap-Gripper](https://github.com/XenseRobotics-AI/TacCap-Gripper)
    **v0.3.2** 核对,SDK 需要按 [准备与自检](follower-setup.md#install) 单独克隆、单独安装。

    数采仓库 `xense-taccap-lerobot` 自带的 SDK 子模块仍是 0.1.9 系列,接口与本章差别很大
    (控制器、坐标方向、固件门槛都不同)。**不要拿数采环境里的 SDK 跑本章的命令**,两个环境分开装。

## 它和主夹爪有什么不同 {#vs-leader}

两种夹爪用同一块主控板、同一套串口协议,区别在于有没有电机、固件是哪一版:

| | 主夹爪(Leader) | 从夹爪(Follower) |
|---|---|---|
| 用途 | 手持采集,读开合 | 装在机器人末端,执行开合与夹持 |
| 执行器 | 无 | RobStride EL05 电机,主控板经 CAN 总线驱动 |
| 供电 | USB Type-C | USB Type-C(主控)+ **24V**(电机) |
| 开合量来源 | 编码器 | 电机位置 |
| IMU / 编码器 / 按键 | 有 | **没有**(读 IMU、编码器会报 `NACK: InvalidCmd`) |
| 腕部相机与鱼眼内参 | 有 | 有 |
| 行程标定 | 手动运行 `calibrate.py` | **上电自动标定**,不需要手动标 |
| SDK 类 | `LeaderGripper` | `FollowerGripper` |
| 序列号末位字母 | `m` | `s` |
| 随 SDK 0.3.2 附带的固件 | 1.2.5 | 1.2.9 |

主夹爪和从夹爪的固件**各自编号**,同一套设备里两边版本号不同是正常的,只在同一角色内比较版本。

## 序列号 {#sn}

固件里烧录的序列号同时给出左右和主从,例如 `TCGU01A24A0001s`:

- **最后一个字母**是角色:`m` = 主夹爪,`s` = 从夹爪。刷固件时按它选镜像,与装在哪只手无关。
- **流水号末位**的单双数是侧别:单数 = 左,双数 = 右。

SDK 只认固件烧录的序列号,不认 USB 转串口芯片自带的那个序列号。

从夹爪的机械结构不分左右,但序列号里仍带侧别;两只从夹爪接在同一台电脑上时,SDK 和示例脚本就靠它区分 `left` / `right`。

!!! warning "SDK 在枚举阶段分不出主从硬件"
    角色只能从序列号末位判断。用 `FollowerGripper` 打开一只主夹爪不会立即报错,要到发电机命令时才失败;
    选设备时务必按角色过滤,见 [找到设备](follower-setup.md#discover)。

## 电机 {#motor-model}

从夹爪里装的是 RobStride **EL05** 电机:

| 持续堵转额定 | 额定力矩 | 力矩量程 | 速度量程 |
|---|---|---|---|
| 1.1 N·m | 1.8 N·m | 6.0 N·m | 50 rad/s |

- **持续堵转额定**是爪子顶住物体时可以一直保持的力矩,也是夹持力的默认值和上限。
- **额定力矩**是运动过程中的瞬时上限。

SDK 从夹爪读出这些额定值,控制器配置和运动安全包络都按它生成,不需要你填写。

## 安全由固件负责 {#safety-model}

控制从夹爪时,真正兜底的保护在夹爪固件里,不在电脑上:

- 固件以 500 Hz 执行**运动安全包络**(力矩上限、按发热降额、温度墙)和堵转判定。
  所有运动命令都要经过这一层,任何程序都绕不过去。
- SDK 在电脑上**不做**第二套接触检测或堵转保护。爪子被物体挡住时,控制器的力矩用满就是"夹住了"。
- 电脑与夹爪之间断链超过 300 ms,固件进入零速保持(0.35 N·m);超过 30 s 后电机失能。

!!! danger "运动安全包络出厂时是关的"
    包络需要每台写一次(掉电保留)。不写的话,爪子顶住硬物时会请求约 12 N·m,
    把 24V 电源拉垮,电机欠压保护动作,**夹爪松手、USB 断开**。
    第一次让从夹爪动起来之前,先按 [写入运动安全包络](follower-setup.md#envelope) 做完这一步。

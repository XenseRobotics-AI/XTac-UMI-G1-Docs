# 开箱、接线与供电

本页指导您把开箱后的各部件接成一套能通电运行的系统：依次连接夹爪、头显与背包，再接通电源（电源适配器或充电宝二选一）。

**预期状态**：背包正常通电，主夹爪指示灯绿色常亮。确认后，前往[网络与控制台入口](network.md)打开控制台。

## 开箱核对 {#unbox}

箱内物品与数量见[产品线与配置对比](../product/editions.md)。接线前核对以下三项：

1. **主夹爪（XTac-UMI G1）**
    - 一左一右两只：序列号末位单数为左、双数为右，见[序列号与左右识别](../common/gripper.md#sn)。
    - Type-C 线的锁紧接头完好，夹爪接口内无异物。
2. **背包机身标签**
    - 印有这台设备的 SN、热点名与密码、设备名，认机与联网时要用，不要撕掉，见[认机看标签](network.md#label)。
3. **头显配置**
    - 已按 [Pico4 头显与追踪器](../common/pico4.md) 完成配置：开启开发者模式、灭屏与休眠设为「永不」、两只追踪器已配对、已安装 XTac-UMI XR。

!!! note
    接线本身不依赖以上软件配置，但没有提前配好，头显将无法建立连接。

## 背包接口 {#ports}

| 接口 | 位置 | 接什么 |
|---|---|---|
| UMI-L / UMI-R | 两侧 | 左 / 右夹爪，Type-C 锁紧线 |
| PICO | 前面板 | 头显，Type-C 有线连接 |
| HOST1 / HOST2 | 前面板 | USB 主机接口，可接平板等设备 |
| DC IN | 后面板 | 12V 供电输入，接适配器或充电宝 |
| 网口 | 后面板 | RJ45，接路由器 LAN 口 |
| TF、HDMI、耳机 | 后面板 | 日常采集不用 |

接口位置示意图见[认识数采背包](../product/backpack.md#ports)。

## 接线与拔线顺序 {#order}

顺序固定：夹爪 → 头显 → 背包上电。

1. 接夹爪：Type-C 锁紧线带螺钉的一端接夹爪本体，旋紧锁紧螺钉；另一端接背包侧面，左爪接 UMI-L，右爪接 UMI-R。夹爪由这根线总线供电，不需要单独电源。
2. 接头显：头显用头显连接线（Pico → Pack）接背包 PICO 口，[适配器供电](#adapter)与[充电宝供电](#powerbank)两种方式接法相同。
3. 给背包上电：DC 口接适配器或充电宝。开机后夹爪指示灯绿常亮即待机；接着把平板插到背包的 `HOST` 口打开控制台，见[平板插 USB](network.md#tablet)（灯语见[夹爪按键、指示灯与语音](gripper.md#buttons-leds)）。

拔线顺序相反：先停止录制，再拔背包端，最后松开锁紧螺钉拔夹爪端。上下电与插拔线缆时注意防静电。

!!! warning "先锁紧夹爪端，再接背包端"
    锁紧螺钉没旋紧，采集中线缆一松动夹爪就掉线，系统日志会反复出现 `mcu ... disconnected / reconnected`，这一条数据就废了。

## 供电方式选择 {#power}

两种方式下，夹爪与头显的接法完全相同，只是背包的电源不同：

| | 适配器供电 | 充电宝供电 |
|---|---|---|
| 适用场景 | 有插座的固定工位 | 离开插座的移动采集 |
| 电源 | 12V 3A 电源适配器，接市电 | 箱内充电宝（20000mAh，45W） |
| 接到背包 DC 口的线 | 适配器直连 | 0.3m 12V PD 电源线，用充电宝的 12V 输出 |

!!! note "头显电量会缓慢下降"
    头显只接一根线，背包经它给头显供电，但供电不足以完全抵消头显功耗，电量仍会以约 1–2W 的净消耗缓慢下降；电量耗尽头显会关机，采集随之中断。开工前把头显充满电，长时间采集留意电量图标（在[电源策略](../common/pico4.md#pico-system)里设为常驻显示）。

### 适配器供电 {#adapter}

![适配器供电接线：左右夹爪接背包两侧，头显 Type-C 接 PICO 口，适配器接 DC 口](../assets/product/backpack-wiring-adapter.webp)

1. 左、右主夹爪分别接背包的 `UMI-L` 和 `UMI-R` 口。
2. 用头显连接线（Pico → Pack）把头显接到背包的 `PICO` 口。
3. 12V 3A 适配器接背包 `DC` 口，再插市电。

### 充电宝供电 {#powerbank}

![充电宝供电接线：左右夹爪接背包两侧，头显接 PICO 口，充电宝经 0.3m 12V PD 电源线接 DC 口](../assets/product/backpack-wiring-powerbank.webp)

1. 取出箱内的充电宝（20000mAh，45W）。
2. 夹爪与头显的接法同[适配器供电](#adapter)。
3. 用 0.3m 12V PD 电源线把充电宝接到背包 `DC` 口。

| 线 | 接法 |
|---|---|
| 夹爪连接线（1.5m 双 C）×2 | 左 / 右夹爪 ↔ 背包 UMI-L / UMI-R |
| 头显连接线（Pico → Pack，1.5m 双 C） | 头显 Type-C 口 ↔ 背包 PICO 口 |
| 12V PD 电源线（0.3m） | 充电宝 ↔ 背包 DC 口 |

背包功耗约 20W，充电宝续航约 3.5–4 小时，见[技术参数](../product/specs.md#backpack)。

!!! warning "采集中不要往充电宝上加设备"
    部分充电宝接上第二台设备时会停掉原有输出口，背包会当场断电。所有线在开录前接好。

## 头显接背包 {#pico-link}

1. **启动与连接**：头显与背包只能有线连接，确认头显 Type-C 口已按上面的接线连到背包 `PICO` 口。戴上头显打开 XTac-UMI XR，**不勾选**「USB网络」，「PC IP」留空（默认连接 `192.168.100.1`），点「连接」。
2. **状态提示**：XR 右上角是折叠按钮。追踪器精度不准或与背包断开时，XR 与控制台监控页都会显示图标提示，界面说明见 [XTac-UMI XR 界面](../common/pico4.md#pico-toolkit-ui)。
3. **作业准备**：站到作业位、面朝作业方向再打开 XR，首次启动 XR 的位置就是[世界坐标系原点](../common/pico4.md#pico-frame)。**采集过程中不要重启 XR。**

!!! warning "头显灭屏与休眠必须设为「永不」"
    头显灭屏后停止工作，位姿数据随之中断。在头显的 开发者选项 → 企业设置 → 电源策略 里把系统休眠和灭屏时间都设为「永不」，步骤见 [Pico4 头显与追踪器](../common/pico4.md#pico-system)。

!!! danger "录制中不要碰头显连接线"
    拔掉或松动会让设备立即停止并作废当前这条录制，见[录制中头显断联](monitor-record.md#pico-disconnect)。

## 上电后核对 {#verify}

打开控制台后核对以下三项，任何一项不对就回头检查接线：

1. **相机路数**：顶栏右侧「相机路数」显示 在线数 / 总数，「双爪」模式应为 6 / 6。少一路多半是夹爪线没锁紧或没插到底。
2. **夹爪指示灯**：正常为绿色常亮。红色爆闪表示夹爪端自检异常；红色常亮表示背包侧检测到夹爪掉线。
3. **采集模式**：当前项目的[采集模式](system.md#capture-mode)与实际接法一致（「双爪」「双爪 + 头显双目」「双爪 + 头显右单目」，可在系统页查看）。头显连上后，监控页的位姿视图应随手移动，见[画面与位姿检查](monitor-record.md#checks)。

**异常处理**：上电没反应或头显时断时续，先换线、换口试。`DC` 口、`PICO` 口或 `USB` 口本身接触不良属硬件问题，记下机身 SN 联系技术支持，不要用力掰扯接口，见[故障排查](troubleshooting.md)。

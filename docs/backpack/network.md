# 网络与控制台入口

本页讲怎么打开 XTac-UMI Collector 控制台（下称控制台）。**推荐随箱平板插 USB**，还能一步把背包和平板接入现场 WiFi。

## 认机看标签，不记 IP {#label}

![机身标签：SN、WiFi 名、密码、IP 与 mDNS 地址](../assets/product/backpack-label.webp){ width="420" }

标签印有 SN、热点名与密码、IP 与设备名。

- **标签上的 IP**：热点固定地址 `192.168.44.1`，只在连热点时可用。
- **现场网络 IP**：每台不同且会变，别写进流程。
- **认机**：用 SN（系统 → [设备信息](system.md#device-info)）和热点名。

## 推荐：平板插 USB {#tablet}

平板用数据线接背包前面板 `HOST1` 或 `HOST2` 口并解锁，背包自动在平板上打开 系统 → 网络 / 配网 页，免连 WiFi、免输地址。

![平板插 USB 后自动打开的网络 / 配网页](../assets/backpack/tablet-usb-network-settings.webp)

- 随箱平板已在产线授权，插上即用。
- 恢复出厂或撤销 USB 调试授权后不再自动打开，按[故障排查](troubleshooting.md#tablet-adb)重新授权。

### 用平板给背包配网 {#tablet-wifi}

此页选现场 5 GHz WiFi、输密码，背包和平板**同时接入**。背包确认同网后平板切到背包 WiFi 地址，可拔 USB。

## 背包的三个网络口 {#interfaces}

| 网络口 | 是什么 | 用途 |
|---|---|---|
| 有线 | 网口接路由器，自动获取 IP，可静态 | 实验室 / 固定工位，带宽最稳 |
| 无线 | 背包连现场 5 GHz WiFi | 多人同网访问 |
| 热点 | 背包自己的 5 GHz 热点，地址固定 `192.168.44.1` | 无平板、无现场网络时用 |

## 背包热点 {#softap}

无平板时：

1. 手机、平板或电脑连热点（名字与密码见标签）。
2. 浏览器打开 `http://192.168.44.1`。

!!! note "新设备首次开机热点是关闭的"
    在 系统 → [网络 / 配网](system.md#wifi)「开启热点」，设备会记住；可先[平板插 USB](#tablet) 进控制台再开。热点只有 5 GHz，只支持 2.4 GHz 的设备搜不到。

- iOS / Safari 须敲全 `http://` 前缀。
- 多台背包时，连前核对热点名与标签。
- 关掉其他已保存网络的「自动连接」，防采集时跳网。

## 设备名访问 {#mdns}

- 同网时用标签最后一行的 `http://xense-xxxxxx.local` 访问，免记 IP。
- 改名或关闭在 系统 → [网络 / 配网](system.md#wifi)。
- Windows 与部分安卓手机打不开 `.local`，改用[网络下拉](#status)里的 IP。

## 接入现场网络 {#lan}

### 有线 {#wired}

- 网口接路由器 LAN 口即用；同路由器的电脑用[网络下拉](#status)里的有线 IP 或设备名访问。
- **Ubuntu**：系统设置里勾选 Wired：

![Ubuntu 有线网络开关](../assets/backpack/ubuntu-wired.webp){ width="480" }

无 DHCP（背包与电脑网线直连）或 IT 要求固定地址时才配静态 IP，见 系统 → [有线 IP](system.md#wifi-wired)。

### 现场 WiFi {#site-wifi}

- **最简单**：[平板插 USB 配网](#tablet-wifi)，背包和平板一起接入。
- **只配背包**：系统 → [连现场 WiFi](system.md#wifi-site)。
- 背包只连 5 GHz WiFi。

## 核对当前网络状态 {#status}

顶栏左侧的 IP 下拉汇总本机全部入口，换网后不确定用哪个地址先看这里。

- **包含**：有线 IP、无线 IP 与所连热点、自身热点的 SSID / 密码 / 网关、mDNS 设备名。
- **折叠态**：只显示「此刻最该用来连它的地址」（有线 > 无线 > 热点 取首个可用）；点开见全部。

![顶栏网络下拉](../assets/backpack/network-dropdown-live.webp)

## 按场景选接入方式 {#choose}

| 场景 | 推荐方式 |
|---|---|
| 日常采集，用随箱平板 | [平板插 USB](#tablet)，背包自动打开控制台 |
| 实验室 / 固定工位，自备路由器 | [有线](#wired)接路由器 LAN 口，用[网络下拉](#status)里的地址访问 |
| 客户现场，网络不可控 | [平板插 USB](#tablet)，或开启[热点](#softap) |
| 现场有 5 GHz WiFi，多人同时访问 | 平板把背包[配上现场 WiFi](#site-wifi)，同网电脑直接访问 |
| 背包与笔记本网线直连，无路由器 | 两侧各配同网段[静态 IP](#wired) |
| 怎么都连不上 | 平板插 USB 进控制台查网络，仍不行见[故障排查](troubleshooting.md) |

## 高级排查：由技术支持处理 {#ssh}

- **日常操作在控制台**：地址看[网络下拉](#status)；有线地址、网关、「未插线」等状态，及连现场 WiFi、改有线 IP，在 系统 → [网络 / 配网](system.md#wifi)。
- **设备后台只供技术支持诊断**，**请勿自行登录或改动系统配置**：控制台看不到这些改动，配错连热点入口都会失去。

按本页与[故障排查](troubleshooting.md)试过仍连不上，把这些交给技术支持：

- 机身 SN，及所用入口（热点 / 设备名 / 有线 IP）；
- [网络下拉](#status)里的地址，及 系统 → [网络 / 配网](system.md#wifi) 页的有线状态与当前外网连接；
- 界面上的报错原文。

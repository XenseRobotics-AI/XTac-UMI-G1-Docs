# 网络与控制台入口

本页介绍如何打开 XTac-UMI Collector 控制台（下称控制台）。推荐用随箱平板通过 USB 连接，这种方式还能把数采背包和平板同时接入现场 WiFi。

## 设备识别：看标签，不记 IP {#label}

![机身标签：SN、WiFi 名、密码、IP 与 mDNS 地址](../assets/product/backpack-label.webp){ width="420" }

机身标签印有设备的 SN、热点名与密码、IP 及 mDNS 地址。使用时注意：

- **热点 IP**：标签上的 IP（`192.168.44.1`）是热点固定地址，只在连接这台设备自己的热点时可用。
- **现场网络 IP**：接入现场网络后，每台设备的 IP 都不同且会变，不要写进固定流程或配置文件。
- **设备识别（认机）**：统一用 SN（在 系统 → [设备信息](system.md#device-info) 查看）和热点名。

## 推荐方式：平板插 USB {#tablet}

用数据线把平板接到背包前面板的 `HOST1` 或 `HOST2` 口，并解锁平板。连接成功后，背包会自动在平板上打开 系统 → 网络 / 配网 页，不用手动连 WiFi 或输入地址。

![平板插 USB 后自动打开的网络 / 配网页](../assets/backpack/tablet-usb-network-settings.webp)

- **即插即用**：随箱平板已在产线完成授权，插上 USB 即可使用。
- **重新授权**：平板恢复出厂或撤销了 USB 调试授权后，不再自动打开，按[故障排查](troubleshooting.md#tablet-adb)重新授权。

### 用平板给背包配网 {#tablet-wifi}

在这一页选择现场 5 GHz WiFi 并输入密码，背包和平板会**同时接入**这个网络。确认背包已在同一网络后，平板会自动切换到背包的 WiFi 地址，这时就可以拔掉 USB 线。

## 背包的网络接口 {#interfaces}

| 网络口 | 是什么 | 用途 |
|---|---|---|
| 有线 | 网口接路由器，自动获取 IP，可静态 | 实验室 / 固定工位，带宽最稳 |
| 无线 | 背包连现场 5 GHz WiFi | 多人同网访问 |
| 热点 | 背包自己的 5 GHz 热点，地址固定 `192.168.44.1` | 无平板、无现场网络时用 |

## 背包热点 {#softap}

没有平板时，可以通过热点访问背包：

1. 用手机、平板或电脑连接背包热点（名称与密码见机身标签）。
2. 在浏览器中访问 `http://192.168.44.1`。

!!! note "新设备首次开机热点是关闭的"
    在 系统 → [网络 / 配网](system.md#wifi) 页点「开启热点」，设备会记住这个设置；也可以先[平板插 USB](#tablet) 进入控制台再开启。热点只有 5 GHz，只支持 2.4 GHz 的设备搜不到。

- **iOS / Safari**：地址栏必须输入完整的 `http://` 前缀。
- **多台背包**：连接前核对热点名与机身标签一致。
- **防止跳网**：关闭其他已保存网络的「自动连接」，避免采集中途切换网络。

## 设备名访问 {#mdns}

在同一网络下，可以用标签最后一行的 `http://xense-xxxxxx.local` 访问，不用记 IP。改名或关闭在 系统 → [网络 / 配网](system.md#wifi)。

!!! note
    Windows 与部分安卓手机无法解析 `.local` 地址，改用[网络下拉](#status)里的 IP 访问。

## 接入现场网络 {#lan}

### 有线接入 {#wired}

- 把背包网口接到路由器 LAN 口即可，同一路由器下的电脑用[网络下拉](#status)里的有线 IP 或设备名访问。
- **Ubuntu 电脑**：需要在系统设置里打开 Wired 开关：

![Ubuntu 有线网络开关](../assets/backpack/ubuntu-wired.webp){ width="480" }

只有在没有 DHCP（背包与电脑网线直连）或 IT 要求固定地址时，才需要配置静态 IP，见 系统 → [有线 IP](system.md#wifi-wired)。

### 现场 WiFi 接入 {#site-wifi}

- **最简单**：[平板插 USB 配网](#tablet-wifi)，背包和平板一起接入。
- **只配背包**：系统 → [连现场 WiFi](system.md#wifi-site)。
- **频段**：背包只支持 5 GHz WiFi。

## 核对当前网络状态 {#status}

顶栏左侧的 IP 下拉汇总了本机的全部入口。换网后不确定该用哪个地址时，先看这里。

- **包含信息**：有线 IP、无线 IP 与所连热点、自身热点的 SSID / 密码 / 网关、mDNS 设备名。
- **折叠时**：只显示「此刻最该用来连它的地址」，按 有线 > 无线 > 热点 的顺序取第一个可用的。
- **展开时**：点开可查看全部网络信息。

![顶栏网络下拉](../assets/backpack/network-dropdown-live.webp)

## 按场景选择接入方式 {#choose}

| 场景 | 推荐方式 |
|---|---|
| 日常采集，用随箱平板 | [平板插 USB](#tablet)，背包自动打开控制台 |
| 实验室 / 固定工位，自备路由器 | [有线](#wired)接路由器 LAN 口，用[网络下拉](#status)里的地址访问 |
| 客户现场，网络不可控 | [平板插 USB](#tablet)，或开启[热点](#softap) |
| 现场有 5 GHz WiFi，多人同时访问 | 平板把背包[配上现场 WiFi](#site-wifi)，同网电脑直接访问 |
| 背包与笔记本网线直连，无路由器 | 两侧各配同网段[静态 IP](#wired) |
| 怎么都连不上 | 平板插 USB 进控制台查网络，仍不行见[故障排查](troubleshooting.md) |

## 高级排查：由技术支持处理 {#ssh}

!!! warning "设备后台只供技术支持诊断"
    **不要自行登录后台或改动系统配置**：控制台看不到这些改动，配置错误可能连热点入口都会失去。

日常操作都在控制台完成：地址看[网络下拉](#status)；有线地址、网关、「未插线」等状态，以及连现场 WiFi、改有线 IP，都在 系统 → [网络 / 配网](system.md#wifi)。

按本页与[故障排查](troubleshooting.md)尝试后仍连不上，请收集以下信息交给技术支持：

1. 机身 SN，以及所用入口（热点 / 设备名 / 有线 IP）。
2. [网络下拉](#status)里的地址，以及 系统 → [网络 / 配网](system.md#wifi) 页的有线状态与当前外网连接。
3. 界面上报错原文的截图。

# 升级与 OTA

控制台升级在 系统 → 系统更新 页完成；夹爪固件在 系统 → 夹爪配置 页刷写，见[夹爪固件](#gripper-firmware)。

![系统更新页](../assets/backpack/update.webp)

## 导入升级包 {#bundle}

升级包是技术支持提供的 `.tar.zst` 文件，文件名里带版本号，如 `taccap-collector-v0.4.3-….tar.zst`。它只更新控制台程序，不含夹爪固件、相机参数包，也不动采集数据。

1. 停止录制。
2. 「上传固件包」→ 选择 `.tar.zst` →「上传并校验」。
3. 校验通过后，在「待应用版本」卡核对版本号。
4. 「应用更新并重启」→ 确认。服务重启约需 1 分钟，提示「更新已应用」即完成；超时就手动刷新页面。
5. 到[设备信息](system.md#device-info)确认版本和构建时间已更新。

校验不通过时设备拒收，原因写在「上次错误」，当前版本照常运行。常见原因：文件损坏或没传完、版本跨度太大或比当前版本旧。

!!! note "部分修复要由技术支持处理"
    少数修复涉及设备系统组件，不在升级包里，现场也无法操作。设备是否需要，以技术支持的通知为准。「上传固件包」只接受 `.tar.zst` 升级包，技术支持给的其他文件不要往这里传。

## 回滚 {#rollback}

升级时设备会保留上一版。新版启动失败、文件损坏或中途断电，设备都会自动退回上一版，不会变砖。

手动回滚：「回滚」卡显示「可回滚」时，点「回滚到上一版本」→ 确认。只能退一步；出厂后还没升级过的设备没有上一版可退。

升级与回滚都不影响录制数据、项目、上传配置和网络配置。

## 夹爪固件 {#gripper-firmware}

夹爪固件不走升级包，在 系统 → [夹爪配置](system.md#gripper) 页下方的「夹爪固件升级」里直接刷，不需要电脑。固件文件与是否需要刷，见 PC 版[固件 OTA 升级](../pc/versions.md#ota)。

1. 停止录制，且没有进行中的开合标定。
2. 选目标爪（左 / 右）→ 选 `.bin` →「上传并刷写」→ 确认。
3. 提示「固件已刷写完成，设备正在重启」后，**给背包断电再上电**（或拔插该夹爪的 Type-C 线），否则夹爪会丢数据。
4. 到[设备信息](system.md#device-info)核对固件版本；标定卡显示「未标定」时回[夹爪配置](system.md#gripper)重新标定。

刷写中途可以「中止」，失败了重来即可，不会刷坏。

!!! danger "按主从选固件，刷写时不要断电"
    主夹爪（SN 末位 `m`）刷 `tc-gu-01-master.bin`，从夹爪（SN 末位 `s`）刷 `tc-gu-01-slave.bin`，按主从不按左右。刷错夹爪无法启动，需返厂恢复；写入过程中断电或拔线也会损坏固件。

# 夹爪按键、指示灯与语音 {#buttons-leds}

背包版里，夹爪的两个侧边按键用来开始、停止和删除录制，指示灯反馈当前状态，设备还会做语音播报。按键与灯语由背包上的 XTac-UMI Collector 接管，不需要浏览器在线。夹爪怎么接、序列号怎么分左右见[夹爪连接与序列号](../common/gripper.md)。

![主夹爪操作部件示意图（接口 / 按键 / 指示灯）](../assets/hardware/master-controls.webp){ width="480" }

## 按键 {#buttons}

按键状态机跑在背包上，**不需要浏览器在线**；录制中双击、右爪长按一律静默忽略（防手抖）；没有可删条目时双击会被拒绝（黄快闪）。

| 手势 | 动作 |
|---|---|
| **右爪长按** | 开始录制 |
| **左爪长按** | 停止录制 |
| **左爪双击** | 进入删除确认（灯紫闪，5 秒无操作自动退出） |
| 确认态再**双击** | 删除上一条（灯紫常亮 3 秒，这 3 秒同时是冷却期，期间双击不响应） |
| 确认态**左爪长按** | 取消删除 |
| 确认态**右爪长按** | 放弃删除并立即开始新录制（上一条保留） |
| 录制中**右爪单击** | 在这条录制里打一个 subtask 标记（子任务分段点），响一声提示音 |

绑定爪位（右开 / 左停）、键位时序与灯语是全机队固定值，现场不可调、控制台里也没有改的入口；当前生效值在控制台 系统 → 采集设置 页查看（见[系统设置](system.md)）。

## 指示灯 {#leds}

| 灯 | 颜色与显示模式 | 含义 |
|---|---|---|
| <span class="tc-lamp green solid"></span> | 绿 常亮 | 待机：可以开录 |
| <span class="tc-lamp green breathe"></span> | 绿 呼吸 | 录制中（1 秒一个明暗周期） |
| <span class="tc-lamp white flash"></span> | 白 闪一次 | 保存正常（亮 0.4 秒） |
| <span class="tc-lamp amber solid"></span> | 黄 常亮 | 开录失败（亮 2 秒），或录制中出现致命问题（长亮不灭） |
| <span class="tc-lamp amber pulse"></span> | 黄 脉冲 | 数据可疑：录着，但那条质量存疑（亮 0.2 秒、灭 0.8 秒，共 3 次） |
| <span class="tc-lamp amber strobe"></span> | 黄 快闪 | 动作被拒，如没有可删条目时双击（0.1 秒明灭，共 3 次） |
| <span class="tc-lamp purple blink"></span> | 紫 闪 | 删除确认中，等你再双击；0.3 秒明灭，超时自动取消 |
| <span class="tc-lamp purple solid"></span> | 紫 常亮 | 刚删完的 3 秒冷却期，期间双击不响应 |
| <span class="tc-lamp red solid"></span> | 红 常亮 | 系统问题（如夹爪掉线，由背包侧点亮） |
| <span class="tc-lamp red burst"></span> | 红 爆闪 | 夹爪端问题（夹爪自己点亮，不经过背包） |

录制中是绿呼吸，红色只代表故障。「快闪」和「脉冲」都是黄色，差别在节奏：快闪密集、脉冲稀疏。控制台 系统 → 采集设置 页把这张表做成了会动的对照表，按实际形状与节奏演示，一眼可辨（见[系统设置](system.md)）。

## 语音播报 {#voice-cues}

采集时双手都在夹爪上、眼睛盯着现场，所以设备会在关键时机**从 Pico 头显里播报语音**，戴着头显就能听到，与灯语互补；不需要平板在旁边，也不受浏览器影响。头显未连接时（例如「pico连接失败」这一句）改由数采背包的喇叭播放。

| 时机 | 播报 |
|---|---|
| 开始录制 | 「录制开始」 |
| 一条录完 | 「录制完成请重置环境」，提示复位现场、准备下一条 |
| 录制中出现严重问题 | 「录制失败」，这一条录废了 |
| 录制中夹爪掉线 | 「夹爪连接失败」 |
| 录制中头显掉线 | 「pico连接失败」 |
| 录制中追踪器掉线 | 「Tracker 连接失败」：头显可能仍在线，先检查手上的追踪器 |
| 录制中右爪单击打标记 | subtask 标记提示音（不含语音） |

- **语言**：中文或英文，默认跟随控制台界面语言。
- **设置**：开关、语言、音量与逐句试听在 系统 → [采集设置](system.md#voice)。
- 播报内容与时机固定，现场不可更改。

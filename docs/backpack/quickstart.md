# 一页速通

本页带您从设备开机走到导出第一份数据集，按顺序操作即可。

!!! note "开始前确认"
    - **头显与追踪器**：Pico 系统已升级，已安装 XTac-UMI XR，两只追踪器已配对，见 [Pico4 头显与追踪器](../common/pico4.md)。
    - **夹爪标定**：主夹爪已完成标定，见 控制台 → 系统 → [夹爪配置](system.md#gripper)。

## 1. 接线与上电 {#power-on}

1. **连接主夹爪**：两只主夹爪分别接数采背包的 `UMI-L` 和 `UMI-R` 口。
2. **连接头显**：用 Pico → Pack 连接线，把头显接到背包的 `PICO` 口。
3. **给背包供电**：
    - 固定工位：接电源适配器。
    - 移动采集：接充电宝。

![充电宝供电接线：左右主夹爪与头显接数采背包，充电宝接背包 DC 口](../assets/product/backpack-wiring-powerbank-diagram.webp)

## 2. 打开控制台 {#console}

1. **连接平板**：用数据线把平板接到背包的 `HOST1` 或 `HOST2` 口。
2. **等待打开**：连接成功后，控制台会自动在平板上打开。

控制台没有自动打开时，见[故障排查](troubleshooting.md#tablet-adb)。

## 3. 连接头显 {#headset}

1. **佩戴头显**：面朝作业方向戴好头显。
2. **启动应用**：打开 XTac-UMI XR。
3. **网络设置**：**不勾选**「USB网络」，「PC IP」留空（默认连接背包的 `192.168.100.1`）。
4. **建立连接**：点「连接」，网络状态显示「连接成功」即完成。

![XTac-UMI XR 控制台：连接成功](../assets/pico4/xr-console-connected.webp){ width="560" }

!!! warning "采集期间不要重启 XR 应用"
    重启会重设世界坐标系原点，同一数据集里的位姿就对不上了。

## 4. 选择项目与任务 {#project}

1. **选择或新建**：在控制台「实时监控」页底部选择项目和任务；还没有的话，选「新建项目…」或「新建任务…」。
2. **填写参数**：
    - **采集模式**：新建项目时选定，例如「双爪 + 头显双目」，见[采集模式](monitor-record.md#project-task)。
    - **任务指令**：新建任务时填写清晰的自然语言指令。

## 5. 开录前检查 {#checks}

点录制前，确认以下三项：

- **相机画面**：各路相机都有图像，鱼眼画面清晰。
- **位姿视图**：随手的移动实时变化，左右没有接反。
- **夹爪开合度**：随夹爪实际开合变化。

![实时监控页](../assets/backpack/monitor-live.webp)

「录制」按钮不可用时，页面会写明原因，见[开录门槛](monitor-record.md#record-gates)。

## 6. 用夹爪按键录制 {#record}

| 操作 | 按键 | 反馈 |
|---|---|---|
| 开始录制 | 右爪长按 | 灯转绿色呼吸 |
| 停止录制 | 左爪长按 | 白灯闪一次，已保存 |
| 删除上一条 | 左爪双击，再双击确认 | 紫灯 |

完整手势、灯语与语音见[夹爪按键、指示灯与语音](gripper.md)。

## 7. 导出与上传 {#export}

在控制台「项目」页选中任务，点「导出」：

1. **数据预检**：系统自动检查数据完整性，未通过时按提示处理。
2. **选择去向**：
    - 下载压缩包，保存到本地。
    - 上传到事先配置好的后端（ModelScope、S3、FTP、NFS）。
3. **选择格式**：按下游训练管线选择 LeRobotDataset v3 或 MCAP。

详见[项目、导出与上传](projects-export.md)。
